# Everyday Malay — Recording Rights Record (Template)

Create one record per delivery batch. Store private contracts and personal contact details outside the source repository; this template contains only the rights metadata needed to govern asset use.

| Field | Value |
|---|---|
| Batch ID | |

| Stable audio IDs and filenames | |
| Recording date | |
| License name / written grant reference | |
| Permitted app use and distribution | |
| Territory / term / exclusivity | |
| Editing and slow-variant permission | |
| Compensation terms (reference only) | |
| Signed release stored securely at (private location) | |
| Reviewer and review date | |
| QC reviewer and date | |
| Restrictions / expiration / follow-up | |

Do not invent a license value. The manifest's `license` field remains empty until a written grant is confirmed and recorded here. An asset must not be distributed until the owner verifies that the grant covers the intended beta and future app distribution.
