# Native audio pilot quality-control checklist

Complete one checklist per asset. Any failure returns the item for correction; it does not change linguistic approval status.

- [ ] Stable ID and filename match the manifest.
- [ ] Exact reviewed Malay wording is spoken; no unapproved substitutions or added particles.
- [ ] Intended speaker, register, address terms, and context are appropriate per the item review.
- [ ] Pronunciation and articulation are clear and reviewed by a proficient Malaysian Malay speaker.
- [ ] Normal performance sounds conversational, not read in a flat voice.
- [ ] Slow phrase take remains natural and preserves phrase grouping.
- [ ] Take starts cleanly and has a natural ending; no clipped consonants.
- [ ] No clipping, distortion, distracting noise, room echo, music, or edit artifacts.
- [ ] Loudness is consistent with other assets in this batch; technical settings are recorded by the editor.
- [ ] Correct file format and playback tested in the app on target browsers.
- [ ] Normal and slow selections play the intended files; missing files show a useful fallback state.
- [ ] Rights record and speaker permission are complete and cover app distribution.
- [ ] Reviewer name/date and QC name/date recorded in the appropriate private/source records.

Disposition: Pass / Re-record / Edit permitted / Needs discussion
